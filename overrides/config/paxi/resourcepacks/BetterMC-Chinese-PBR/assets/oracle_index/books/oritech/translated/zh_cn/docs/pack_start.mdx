## 第一次开机

1. 用任务书的老档配方取得启动镍，再做基础燃煤发电机和电缆。
2. 右击目标机器，查看高亮的核心位置。手持机器核心右击，可在空位自动安装。
3. 发电机放煤或木炭，把电缆接到机器；先看电量有没有增加。
4. 只放一份原料试跑，给每种产物留输出空位。

二级核心可用 8 铜锭或铁锭围绕 1 青金石制作。更好的核心主要改善插件扩展能力，并非直接提高加工速度。

## 离心机加水的正确位置

先安装流体处理插件，再把水接到机器本体。插件只开启流体配方，管道不接到插件上。安装后重新打开机器界面，确认状态刷新。

粗铁→碎片锻造炉→团块与碎片→9 碎片合成团块→干式离心。干式路线可以提取镍与铂副产物；直接投铁锭不能代替粗铁。

## 旧农场怎样接入

铁塔供铁→炼钢与造机器。小麦→浓缩小麦→生物质或粗生物聚合物。骨头→粉碎机→骨粉→骨块。蜜脾＋生物质→装配机→黏液球。蜂蜜块与生物钢参与本包的火箭发动机。

先运行小规模供料即可，不要求先建巨型生电机器。原版合成器需要红石脉冲，适合分担骨块、浓缩小麦等重复合成。

## 航天设备怎样连接

工业电源向航天设备供电，储能块接输出面。原油跨模组交接用航天管道向工业储罐推送，再连接工业内部管道。当前版本不要让工业管道从航天储罐反向抽取。

火箭燃料与柴油分别储存，火箭只用航天火箭燃料。每人穿齐航天服、充足氧气，带食物罐和返程物资，再起飞。

## 检查顺序

电量→核心结构→必需插件→输入材料与流体→输出空位。先修好这一个循环，再扩建。
