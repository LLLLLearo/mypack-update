## 主要内容

- **冒险探索**：探索不同维度，挑战地牢，推进天境远征。
- **工业与航天**：发展工业自动化，搭建生产线，准备星际旅行；部分材料、配方和能量传输数值经过调整。
- **中文任务书**：包含入门指引、工业发展、航天探索与 MCA 村庄教学。
- **收集与悬赏**：加入钓鱼协会和饰品悬赏，为收集提供额外目标。
- **村庄生活**：通过 MCA 与村民互动；AI 对话需要自行配置服务和密钥。
- **界面与动作**：配套自定义菜单、游戏内更新日志，以及资源包和光影包。

## 下载与安装

前往 [Releases](../../releases) 下载最新版本附件中的整合包 ZIP。

1. 打开 HMCL。
2. 通过整合包安装入口导入下载的 ZIP，无需手动解压。
3. 等待游戏及加载器依赖下载完成。
4. 启动整合包，打开任务书查看入门指引。

请下载 Release 附件中的安装包orz

## 版本更新

使用 HMCL 自动更新格式安装的实例，通过仓库中的更新清单获取后续更新。更新需要能够访问配置的下载地址。

版本说明见 [Releases](../../releases)，也可以在游戏主菜单中查看更新日志。更新前建议备份重要存档。

## 问题反馈

发现崩溃、任务异常、配方问题或显示错误，请前往 [Issues](../../issues) 提交反馈，并尽量提供：

- 整合包版本及启动器版本。
- 问题出现前的操作和复现步骤。
- 相关截图。
- 崩溃报告或启动器导出的日志。

上传日志或配置前，请移除账号信息、访问令牌和 API 密钥。
